## 🚀 أولاً: خطوات النشر على GitHub و GitHub Pages

### 1. رفع المشروع إلى حسابك على GitHub
افتح موجه الأوامر (Terminal) في مجلد المشروع وقم بتنفيذ الآتي (مع استبدال `YOUR_USERNAME` باسم حسابك على GitHub):

```bash
# 1. تهيئة المستودع وإضافة الملفات
git init
git add .
git commit -m "feat: release academic evaluation platform with Streamlit & GitHub Pages"

# 2. تغيير الفرع إلى main
git branch -M main

# 3. ربط المستودع بحسابك على GitHub (بعد إنشاء مستودع جديد باسم academic-eval-platform)
git remote add origin https://github.com/YOUR_USERNAME/academic-eval-platform.git

# 4. رفع الملفات
git push -u origin main
```

### 2. تفعيل GitHub Pages
1. افتح صفحة المستودع على **GitHub**.
2. اذهب إلى تبويب **Settings** (الإعدادات).
3. من القائمة الجانبية، اختر **Pages**.
4. تحت قسم **Build and deployment**:
   - **Source:** اختر `Deploy from a branch`.
   - **Branch:** اختر `main` واجعل المجلد `/docs`.
   - انقر على **Save**.
5. أو يمكنك اختيار `GitHub Actions` وسيقوم ملف العمل المدمج [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) بنشر الموقع آلياً.
6. سيظهر لك رابط الموقع المباشر:
   `https://YOUR_USERNAME.github.io/academic-eval-platform/`

## ☁️ ثانياً: خطوات النشر على Streamlit Community Cloud

1. توجه إلى منصة **[Streamlit Community Cloud](https://share.streamlit.io)** وسجّل الدخول بحسابك في GitHub.
2. انقر على زر **"New app"**.
3. املأ بيانات التطبيق كالآتي:
   - **Repository:** اختر مستودعك `YOUR_USERNAME/academic-eval-platform`
   - **Branch:** `main`
   - **Main file path:** اكتب `streamlit_app.py`
4. انقر على زر **Deploy!** 🚀
5. سيقوم خادم Streamlit تلقائياً بتثبيت الحزم من [`requirements.txt`](requirements.txt) وتشغيل التطبيق في غضون دقيقة واحدة.
6. ستحصل على رابط دائم ومجاني يمكنك مشاركته مع التدريسيين واللجان الأكاديمية!

## 💻 ثالثاً: التشغيل المحلي على حاسوبك (Local Development)

### الخيار (أ): تشغيل تطبيق Streamlit

## 📋 ميزات المنصة ومطابقتها لضوابط وزارة التعليم العالي

1. **البيانات الشخصية والجامعية:**
   - الجامعة، الكلية، القسم، اللقب العلمي، بيانات الشهادة، والبريد الجامعي الرسمي.
   - دعم زر سريع لتعبئة البيانات النموذجية لقسم هندسة التصميم المعماري - الجامعة التكنولوجية.

2. **المحور الأول: جودة التدريس والتعليم (50%):**
   - احتساب المقررات الدراسية، إدارة الصف، التعليم المدمج، وصف المقرر، والالتزام الوظيفي.
   - دعم خيار "تدريسي غير مكلف بمهام تدريسية" واحتساب الفقرة 5 بنسبة 50%.

3. **المحور الثاني: النشاط العلمي والبحثي (30%):**
   - بحوث المستوعبات العالمية (Scopus/Clarivate).
   - تطبيق **القيد الوزاري الإلزامي:** سقف التقييم 75% كحد أقصى إذا كانت أبحاث سكوباس = 0.
   - التحقق الآلي من معرفات DOI ومطابقة ربع المجلة (Q1-Q4) ومعامل الاستشهاد CiteScore.
   - البحوث المحلية والمؤتمرات والكتب المنهجية المؤلفة والمترجمة والإشراف العلمي.

4. **المحور الثالث: الجانب التربوي والإرشادي (20%):**
   - اللجان الوزارية والجامعية، التعليم المستمر وورش العمل، كتب الشكر والتقدير، والزيارات الميدانية.

5. **المحور الرابع والخامس: مواطن القوة والعقوبات:**
   - بنود القوة (معامل هيرش h-index، براءات الاختراع، المنظومات الإلكترونية...) حتى +5 درجات.
   - خصم العقوبات الانضباطية بالكامل دون وزن من المجموع النهائي.

6. **التفقيط العربي والتقارير الرسمية:**
   - احتساب فوري وتفقيط عربي رسمي مطابق للتعليمات (مثال: "تسعون درجة وخمسة وسبعون بالمائة من الدرجة فقط لا غير").
   - تصدير استمارة 21 الرسمية بصيغة **Word (.docx)**.
   - تصدير استمارة 21 الرسمية بصيغة **PDF**.
   - تصدير **الملف التوثيقي الشامل (Dossier PDF)** مدمجاً مع صور ووثائق الإثبات المعتمدة.
